# 🚀 Borkor Portfolio (E-Portfolio)

เว็บไซต์ **E-Portfolio** ส่วนตัวของ **นายพิสิฐพงค์ ภูมิภักดิ์ (บอกอ / แบ้ง)** จัดทำขึ้นเพื่อรวบรวมประวัติส่วนตัว ผลงานทางวิชาการ สิ่งประดิษฐ์ และกิจกรรมต่างๆ สำหรับใช้ยื่นสมัครเข้าศึกษาต่อในระดับมหาวิทยาลัย รวมถึงเป็นแนวทางให้กับผู้ที่สนใจศึกษาต่อในสายเทคโนโลยีและวิศวกรรม

🌐 **Live Demo:** [https://pisitpong-gif.github.io/bankkismileport/](https://pisitpong-gif.github.io/bankkismileport/)

## 👤 ข้อมูลเจ้าของเว็บไซต์ (Profile & Education)

* **ชื่อ-นามสกุล:** นายพิสิฐพงค์ ภูมิภักดิ์ (ชื่อเล่น: บอกอ / แบ้ง)
* **ระดับการศึกษา:** ชั้นมัธยมศึกษาปีที่ 6 แผนการเรียนเทคโนโลยีและนวัตกรรม
* **สถานศึกษา:** โรงเรียนธัญรัตน์ จังหวัดปทุมธานี

  * 4 ภาคเรียน: `3.94`
  * 5 ภาคเรียน: `3.93`
* **ทักษะและความถนัด (Skills):**
  * 💻 การเขียนโปรแกรม (Coding) และการพัฒนาเว็บไซต์ (Web Development)
  * 📐 การเขียนแบบ 3 มิติ (3D Modeling)
  * 🤖 การต่อวงจรไมโครคอนโทรลเลอร์ (Microcontrollers) หุ่นยนต์ และระบบอัตโนมัติ
  * 📸 การถ่ายภาพดิจิทัล (Digital Photography)

## 🎯 เป้าหมายทางการศึกษาและอาชีพ (Goals & Vision)

* **คณะและมหาวิทยาลัยที่มุ่งหวัง:** 
  * สาขาวิชาเทคโนโลยีวิศวกรรมแมคคาทรอนิกส์ มหาวิทยาลัยเทคโนโลยีพระจอมเกล้าพระนครเหนือ (มจพ.)
  * *เหตุผล:* มุ่งเน้นการศึกษาในสถาบันที่ให้ความสำคัญกับการลงมือปฏิบัติจริงอย่างเข้มข้น
* **เป้าหมายในอนาคต:** 
  * พัฒนาตนเองสู่การเป็นผู้ออกแบบระบบควบคุมอัตโนมัติ (Automation Control Systems) และนักพัฒนาหุ่นยนต์
  * ต่อยอดความรู้และประสบการณ์สู่การเป็นผู้ประกอบการโรงงานอุตสาหกรรมสมัยใหม่

## 🗂️ โครงสร้างเนื้อหาภายในเว็บไซต์ (Website Structure)

1. **หน้าแรก (Hero Section):** 
   * ส่วนแนะนำตัวเบื้องต้น พร้อมรูปโปรไฟล์และปุ่มลัด (Quick Links) สำหรับเข้าถึงส่วนข้อมูลส่วนตัวและผลงานได้อย่างรวดเร็ว
2. **เกี่ยวกับผม (About & Statement of Purpose):** 
   * บอกเล่าเรื่องราวและแรงบันดาลใจด้านวิทยาศาสตร์และนวัตกรรมตั้งแต่มัธยมศึกษาตอนต้นจนถึงมัธยมศึกษาตอนปลาย
   * ประวัติการเป็นตัวแทนเข้าร่วมการแข่งขันโครงงานต่างๆ พร้อมตารางสรุปข้อมูลส่วนตัว
3. **ผลงานและกิจกรรม (Projects & Activities):** 
   * รวบรวมและจัดแสดงผลงานโดดเด่นในช่วงมัธยมปลาย ครอบคลุมทั้งด้านวิชาการ โครงงานสิ่งประดิษฐ์ งานจิตอาสา และกิจกรรมเพื่อส่วนรวม
4. **ช่องทางการติดต่อ (Contact):** 
   * แสดงข้อมูลการติดต่อและแบบฟอร์ม (Contact Form) สำหรับส่งข้อความหาเจ้าของเว็บไซต์ได้โดยตรง
